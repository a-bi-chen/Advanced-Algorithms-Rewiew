# 预算旋转基数树（第 5 节）

*The Budget Rotated Trie*

---

前两节（第 3、4 节）把失败概率一路压到了 $1/n^{n^{1-\varepsilon}}$。代价是 $O(n\log n)$ 个随机比特——每个内部节点一个旋量 $r_i \in [n]$，节点数 $O(n)$。

第 5 节反过来问：**如果我不在乎失败概率是 $1/\text{poly}(n)$ 还是双指数级，随机比特能省多少？**

论文引言把这两个方向叫"自然对偶"：

> *"不是试图在使用最多 $O(n)$ 随机比特的同时最小化失败概率，而是试图在维持标准 $1/\text{poly}(n)$ 失败概率的同时最小化随机比特。"*

最后拿到的是 $\tilde{O}(\log n)$——$O(\log n \log\log n)$ 个比特。$n=2^{20}$ 时，$O(n\log n) \approx 20\text{M}$，$\tilde{O}(\log n) \approx 86$。

省到这个量级有两个后果。第一，再往下省就能推出确定性常数时间字典（引理 6）——一个开放问题，所以 $\tilde{O}(\log n)$ 是"省到没法再省"。第二，第 6 节用预算旋转基数树做组件，随机比特少意味着简洁构造的额外开销也小。

---

# 相关研究

Dietzfelbinger、Gil、Matias 和 Pippenger [10] 也可以在 $(\log n)$ 比特键的场景做到 $O(\log n)$ 随机比特。论文也直说了——这结果"不是新颖的"。

但论文认为自己有两条贡献：一是展示了逐渐增加独立性的哈希函数的一个反直觉用法——不当哈希函数，当伪随机数生成器；二是在第 6 节被用作关键组件。

Celis、Reingold、Segev 和 Wieder [7] 构造了负载均衡哈希族。这是生成 $b_i$ 的理论基础——只用 $O(\log t \log\log t)$ 随机比特，但评估要 $O(\log t \log\log t)$ 时间。后续 Meka 等人 [23] 改到了 $O((\log\log t)^2)$。

---

# 三个修改

出发点是第 3、4 节的旋转基数树，扇出 $n^\delta$（$\delta = 1/4$）。

核心想法是：**不同层级的信息对独立性的要求不一样。** 球到组（$a_i$）只需 $k$ 独立，$k$ 是常数，$O(\log n)$ 比特就够。组内球到桶（$b_i$）需要更强的负载均衡——但规模已经小了（每组 $n^{1-\delta}$ 个球），而且 $b_i$ 的初始化可以摊到多次插入上。

---

## 修改一：少建内部节点

原来的树里需要就建节点，最后 $O(n)$ 个。

新规则：子树至少 $\Delta = \text{polylog } n$ 个元素才建节点。不够 $\Delta$ 的子树整个塞进一个动态融合节点，当迷你字典用。后面超了 $\Delta$ 再补建内部节点，球同时持有两个指针（指向节点和融合节点）。

效果：$m \leq O(n/\Delta) = n/\text{polylog } n$。旋量 $r_i$ 的随机比特降到 $n/\text{polylog } n$——还是太多，但已经迈了一步。

---

## 修改二：拆开桶映射

原来 $\phi(s,c) = (c + r_s) \bmod n$，一个 $r_s$ 管全部。

改成：

$$
\phi(s,c) = ((c + a_s) \bmod n^{\delta}) \cdot n^{1-\delta} + b_s
$$

$n$ 个桶拆成 $n^{\delta}$ 个组，每组 $n^{1-\delta}$ 个桶。$a_s$ 管球去哪个组，$b_s$ 管组内去哪个桶。对固定 $a_s$，$c$ 跑遍 $n^{\delta}$ 个值时 $(c + a_s) \bmod n^{\delta}$ 是一一映射——同一源节点每組至多一个球。

这个拆分把一个"$m$ 节点到 $n$ 桶"的大问题变成了"$m$ 节点到 $n^{\delta}$ 组"加"每组内 $O(n^{1-\delta})$ 球到 $n^{1-\delta}$ 桶"两个小问题，参数规模不同，对哈希函数独立性要求也不同。

---

## 修改三：用哈希函数生成 $a_i$ 和 $b_i$

### 生成 $a_i$

取 $k$ 独立哈希函数 $g: [n] \to [n^{\delta}]$，$a_i = g(i)$。$k$ 是常数，指定 $g$ 只需 $O(\log n)$ 比特，$O(1)$ 求值。

分析用 [[数学工具#k-独立随机变量的尾部界]]（引理 4）：每个源节点向组 $G_i$ 放球是 $k$ 独立的 0-1 变量，$O(n)$ 个球均匀分布，$\mathbb{E}[|G_i|] = O(n^{1-\delta})$。取 $t = n^{1-\delta}$，偏差超 $n^{1-\delta}$ 的概率 $n^{-\Omega(k)} = 1/\text{poly}(n)$。所以 $|G_i| \leq O(n^{1-\delta})$ 高概率成立。

### 生成 $b_i$

每组内最多 $O(n^{1-\delta})$ 球要进 $n^{1-\delta}$ 桶，每个桶负载不能超 $\text{polylog } n$。

$k$ 独立不够了——尾部界给的是多项式概率，桶数也是多项式，Union bound 后兜不住。

Celis 等人 [7] 的负载均衡哈希族 $\mathcal{H}$ 直接解决：取 $t = n^{1-\delta}$，$h \in \mathcal{H}(t)$ 用 $O(\log t \log\log t) = O(\log n \log\log n)$ 比特，把 $t$ 球映射到 $t$ 桶，最大负载 $\text{polylog } n$，成功概率 $1 - 1/\text{poly}(n)$。

机制是"逐渐增加独立性"：$h$ 是 $O(\log\log t)$ 个不同独立性水平哈希函数的叠加——低位要高独立性，高位只需低独立性。总随机比特就省了。

代价是评估时间 $O((\log\log n)^2)$——不是 $O(1)$。论文绕开了：$h$ 不当哈希函数用，当伪随机数生成器。$b_i = h(i)$ 只在建新节点时调一次，修改一保证了每 $\Delta = \text{polylog } n$ 次插入才建节点，且 $\Delta = \Omega((\log\log n)^2)$。评估时间摊到 $\Delta$ 次插入上，每次只多 $O(1)$。

---

# 正确性

组的大小：$X_j$ = 源节点 $j$ 向 $G_i$ 放球，$k$ 独立，$\mathbb{E}[|G_i|] = O(n^{1-\delta})$。引理 4 + Union bound 过 $n^\delta$ 组 → 所有组 $|G_i| \leq O(n^{1-\delta})$，概率 $1-1/\text{poly}(n)$。

组内负载：组 $G_i$ 内球来自 $\leq O(n^{1-\delta})$ 个不同源节点，每源节点至多一球（修改二保证），球去桶 $b_s = h(s)$。$h$ 来自负载均衡族 → 每桶 $\leq \text{polylog } n$，概率 $1-1/\text{poly}(n)$。

两层 Union bound → 全局每桶 $\leq \text{polylog } n$，用动态融合节点实现桶，操作 $O(1)$。

随机比特：$g$ 用 $O(\log n)$，$h$ 用 $O(\log n \log\log n)$，总计 $\tilde{O}(\log n)$。

---

# 为什么 $\tilde{O}(\log n)$ 是最优的

引理 6 的论证很短但结论很硬。

**引理 6**：如果用 $c\log n$ 随机比特能做到失败概率 $< 1/n^c$，那确定性常数时间字典就存在。

**证明**：把哈希表的 $c\log n$ 个随机比特固定为 $0$，得到确定性字典 $D$。假设 $D$ 在某个操作序列上超时。原哈希表有 $n^c$ 种随机比特取值，等可能 → 超时概率 $\geq 1/n^c$。但已知失败概率 $< 1/n^c$，矛盾。□

也就是说：想用比 $\tilde{O}(\log n)$ 更少的随机比特，就得先造出确定性常数时间字典——开放问题。所以 $\tilde{O}(\log n)$ 就是当下最好。

---

# 值得注意

**$h$ 的角色转换**。一个因评估太慢被认为不适合常数时间哈希表的工具，论文换个用法——建节点时才跑一次的随机数生成器——缺点就没了。把工具从原语境里拿出来重新定义用途，这种操作在理论计算机科学里经常出好结果。

---

# 总结

预算旋转基数树用 $\tilde{O}(\log n)$ 比特的随机种子驱动整个哈希表，操作高概率 $O(1)$。本质上是一套随机比特压缩——把随机性的生成推迟、分摊、分级（$k$ 独立管组、负载均衡哈希管桶），在不牺牲操作时间的前提下压到了理论下界。
