# 旋转基数树 — 伪代码实现

*Rotated Radix Trie — Pseudocode*

> 对应论文第 3 节。相关分析：[n叉基数树与旋转基数树](n叉基数树与旋转基数树.md)、[旋转基数树的分析证明](旋转基数树的分析证明.md)

---

## 一、数据结构定义

```
常量:
    n       : 当前键值对数量（也是全局数组 A 的大小）
    Δ       : 每个桶的容量上界 = polylog(n)
    DEPTH   : 树的深度 = Θ(log_n U) = O(1)（因为 U = poly(n)，n 叉树的深度为常数）

类型:
    Key     : Θ(log n) 比特的键
    Value   : Θ(log n) 比特的值
    Ball    : 球，表示内部节点中的一个非空条目，结构为 (源节点ID s, 孩子索引 c)
    Pointer : 指针，结构为 (目标节点ID i', 目标节点的随机旋量 r_i')

全局变量:
    A       : 大小为 n 的数组，每个元素 A[j] 是一个动态融合节点（容量为 Δ）
              存储键值对: (源节点ID i) → 指针 / 值
    r[1..m] : 每个内部节点 i 的随机旋量 r_i ∈ {0, 1, ..., n-1}
    m       : 内部节点数，m ≤ O(n)
```

## 二、核心映射

```
FUNCTION φ(s, c):
    // 将球 (s,c) 映射到桶 j
    // s: 源节点编号, c: 孩子索引 ∈ [n]
    RETURN (c + r[s]) mod n
```

## 三、节点结构

```
CLASS InternalNode(i):
    // 第 i 个内部节点，逻辑上是一个大小为 n 的数组
    // 物理上不分配整个数组——条目通过 φ 分散存储在 A 中

    FIELD r : 随机旋量，初始化为 Uniform({0, 1, ..., n-1})

    // 读取节点 i 的逻辑位置 j 处的指针
    FUNCTION GetChild(j):
        bucket ← φ(i, j)
        result ← A[bucket].Lookup(i)    // 在动态融合节点中查找键 i
        IF result = NIL THEN RETURN NIL
        RETURN result                   // 返回 (i', r_{i'}) 指针

    // 设置节点 i 的逻辑位置 j 处的指针
    FUNCTION SetChild(j, pointer):
        bucket ← φ(i, j)
        A[bucket].Insert(i, pointer)    // 若 bucket 已满 (≥Δ 个条目)，触发溢出
```

## 四、查询操作

```
FUNCTION Query(rootKey):
    // 查询键 rootKey 对应的值
    // 键可以表示为 n 进制数字串: j_1 ∘ j_2 ∘ ... ∘ j_d ∈ [n^d]

    (j_1, j_2, ..., j_d) ← SplitIntoDigits(rootKey)   // 将键分解为 n 进制数字
    currentNodeID ← 1                                   // 从根节点开始

    FOR k = 1 TO d DO:
        node ← GetNode(currentNodeID)
        ptr ← node.GetChild(j_k)                        // 通过 A[φ(i, j_k)] 查找
        IF ptr = NIL THEN
            RETURN NIL                                  // 键不存在
        (nextNodeID, nextRotation) ← ptr
        currentNodeID ← nextNodeID

    // 到达叶子：currentNodeID 对应的"节点"实际存储值
    RETURN GetValue(currentNodeID)
```

## 五、插入操作

```
FUNCTION Insert(rootKey, value):
    (j_1, j_2, ..., j_d) ← SplitIntoDigits(rootKey)
    currentNodeID ← 1

    // 遍历到叶子，沿途创建缺失的内部节点
    FOR k = 1 TO d-1 DO:
        node ← EnsureNode(currentNodeID)                // 节点不存在则创建
        ptr ← node.GetChild(j_k)
        IF ptr = NIL THEN
            // 创建新孩子节点
            newID ← AllocateNode()
            newNode ← InternalNode(newID)
            node.SetChild(j_k, (newID, newNode.r))
            ptr ← (newID, newNode.r)
        (nextNodeID, _) ← ptr
        currentNodeID ← nextNodeID

    // 在叶子节点处存储值
    SetValue(currentNodeID, value)
```

## 六、内部节点的延迟创建

```
FUNCTION EnsureNode(i):
    IF node i 尚未创建 THEN
        CreateNode(i)               // 创建内部节点，生成随机旋量 r_i
        r[i] ← Uniform({0, 1, ..., n-1})
    RETURN GetNode(i)

FUNCTION AllocateNode():
    m ← m + 1
    r[m] ← Uniform({0, 1, ..., n-1})
    RETURN m
```

## 七、初始化

```
FUNCTION Initialize():
    m ← 1                                 // 根节点编号为 1
    r[1] ← Uniform({0, 1, ..., n-1})      // 根节点的随机旋量
    FOR j = 1 TO n DO:
        A[j] ← NewDynamicFusionNode(Δ)     // 每个桶初始化为空融合节点（容量 Δ）
```

## 八、时间复杂度分析

| 操作 | 时间 | 说明 |
|:--:|:--:|------|
| `Query` | $O(1)$ 以高概率 | 深度为常数 d=O(1)，每层在融合节点中查找 O(1) |
| `Insert` | $O(1)$ 以高概率 | 同上，融合节点插入 O(1)（只要不溢出） |
| `Initialize` | $O(1)$ | 延迟初始化旋量 r_i；数组 A 用零初始化模拟技术 |

**失败条件**：任意桶 j 中的条目数超过 Δ（容量上界）。由 [旋转基数树的分析证明](旋转基数树的分析证明.md)，失败概率为 $1/n^{\text{poly}\log n}$。
