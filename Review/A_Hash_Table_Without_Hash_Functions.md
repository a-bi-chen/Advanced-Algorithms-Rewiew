# 无哈希函数的哈希表 —— 基础知识解释

## 一、$(1 + \Theta(1))\log n$ 是什么？

$$
(1 + \Theta(1))\log n = \Theta(\log n)
$$

即常数因子 $1 + \Theta(1)$ 不影响渐近增长率，整体仍为 $\Theta(\log n)$ 量级。

---

## 二、为什么限制每个键值对为 $\Theta(\log n)$ 比特？

这是理论计算机科学（算法与数据结构）中的常见设定，主要有两个原因：

### 1. 衡量总存储空间

存储 $n$ 个这样的键值对，总占用空间为：

$$
n \times \Theta(\log n) = \Theta(n \log n) \ \text{比特}
$$

这通常被用来证明哈希表在「紧凑存储」下的空间下界 —— 即最优哈希表至少需要这么多空间来区分 $n$ 个不同的条目。

### 2. 隐含了键的宇宙大小

如果每个键值对总共只有 $\Theta(\log n)$ 比特，那么键（以及值）可能的取值总数最多为：

$$
2^{\Theta(\log n)} = n^{\Theta(1)}
$$

即**多项式大小**。这意味着哈希表中的键通常被视为从一个大小为 $n^c$（$c$ 为常数）的整数集合中选取。
