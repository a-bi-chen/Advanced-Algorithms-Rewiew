*Amplified Rotated Radix Trie — Pseudocode*

> 对应论文第 4 节。相关分析：[放大旋转基数树](放大旋转基数树.md)、[放大旋转基数树的溢出球界定](放大旋转基数树的溢出球界定.md)

## 一、与旋转基数树的区别

放大旋转基数树在 [旋转基数树](旋转基数树_伪代码.md) 的基础上做了三个关键修改：

| 修改项 | 旋转基数树（§3） | 放大旋转基数树（§4） |
|:--:|:--|:--|
| **扇出** | $n$ | $n^\delta$（$\delta = \epsilon/5$） |
| **溢出处理** | 无（失败即溢出） | 辅助树 $Q$ 存储溢出球 |
| **分析方法** | Chernoff 界 + Union Bound | McDiarmid 不等式 |
| **失败概率** | $1/n^{\text{poly}\log n}$ | $1/n^{n^{1-\epsilon}}$ |

---

## 二、数据结构定义

```
常量:
    n       : 当前键值对数量
    δ       : 扇出指数，δ = ε/5（ε 为用户选择的小正常数）
    fanout  : n^δ（每个内部节点最多 fanout 个孩子）
    Δ       : 每个桶的容量上界 = polylog(n)
    DEPTH   : 树的深度 = Θ(log_{fanout} U) = O(1/δ) = O(1)

全局变量:
    A       : 大小为 n 的数组，每个元素 A[j] 是一个动态融合节点（容量 Δ）
    r[1..m] : 每个内部节点 i 的随机旋量 r_i ∈ {0, 1, ..., n-1}
    m       : 内部节点数，m ≥ n^{1-δ}（因为每个节点最多 fanout 个球）
    Q       : 辅助溢出树（n^δ 叉树），存储溢出球
```

## 三、核心映射（不变）

```
FUNCTION φ(s, c):
    // c ∈ [fanout] = [n^δ]
    // 映射到桶的范围仍然是 [n]
    RETURN (c + r[s]) mod n
```

## 四、溢出处理：辅助树 Q

```
// Q 是一个 n^δ 叉树，用于存储无法放入桶中的溢出球
// 键为球标识 (s, c)，值为对应的指针

FUNCTION Q_Insert(s, c, pointer):
    // 将溢出球 (s, c) 插入辅助树 Q
    // 通过 n^δ 叉树的常数深度逐层查找/创建
    Q.InsertBall(s, c, pointer)          // O(1) 时间

FUNCTION Q_Lookup(s, c):
    // 在辅助树 Q 中查找溢出球
    RETURN Q.LookupBall(s, c)            // O(1) 时间
```

## 五、带溢出处理的桶操作

```
FUNCTION BucketInsert(s, c, pointer):
    j ← φ(s, c)
    IF A[j].Size() < Δ THEN
        A[j].Insert(s, pointer)          // 正常插入到桶中
    ELSE
        Q_Insert(s, c, pointer)          // 桶已满，溢出到 Q

FUNCTION BucketLookup(s, c):
    j ← φ(s, c)
    result ← A[j].Lookup(s)
    IF result ≠ NIL THEN
        RETURN result
    ELSE
        RETURN Q_Lookup(s, c)            // 在溢出树中继续查找
```

## 六、查询操作

```
FUNCTION Query(rootKey):
    (j_1, j_2, ..., j_d) ← SplitIntoDigits(rootKey, fanout)   // n^δ 进制分解
    currentNodeID ← 1

    FOR k = 1 TO d DO:
        node ← GetNode(currentNodeID)
        ptr ← BucketLookup(currentNodeID, j_k)                // 先在 A 中查，再查 Q
        IF ptr = NIL THEN RETURN NIL
        (nextNodeID, _) ← ptr
        currentNodeID ← nextNodeID

    RETURN GetValue(currentNodeID)
```

## 七、插入操作

```
FUNCTION Insert(rootKey, value):
    (j_1, j_2, ..., j_d) ← SplitIntoDigits(rootKey, fanout)
    currentNodeID ← 1

    FOR k = 1 TO d-1 DO:
        node ← EnsureNode(currentNodeID)
        ptr ← BucketLookup(currentNodeID, j_k)
        IF ptr = NIL THEN
            newID ← AllocateNode()
            BucketInsert(currentNodeID, j_k, (newID, r[newID]))
            ptr ← (newID, r[newID])
        (nextNodeID, _) ← ptr
        currentNodeID ← nextNodeID

    SetValue(currentNodeID, value)
```

## 八、内部节点管理

```
FUNCTION EnsureNode(i):
    IF node i 尚未创建 THEN
        CreateNode(i)
        r[i] ← Uniform({0, 1, ..., n-1})
        // 节点 i 最多有 fanout = n^δ 个孩子
    RETURN GetNode(i)

FUNCTION AllocateNode():
    m ← m + 1
    r[m] ← Uniform({0, 1, ..., n-1})
    RETURN m
```

## 九、初始化

```
FUNCTION Initialize():
    m ← 1
    r[1] ← Uniform({0, 1, ..., n-1})
    FOR j = 1 TO n DO:
        A[j] ← NewDynamicFusionNode(Δ)
    Q ← NewAuxiliaryTree(fanout)          // 创建 n^δ 叉辅助树
```

## 十、时间复杂度与空间分析

| 操作 | 时间 | 说明 |
|:--:|:--:|------|
| `Query` | $O(1)$ 以高概率 | 深度 O(1/δ) = O(1)，每层查桶 + 溢出树 O(1) |
| `Insert` | $O(1)$ 以高概率 | 同上 |
| 空间 | $O(n + q \cdot n^\delta)$ | q = 溢出球数；若 $q \leq n^{1-\epsilon}$，空间 $O(n)$ |

**关键保证**：由 [McDiarmid 不等式分析](放大旋转基数树的溢出球界定.md)，$\Pr[q \geq n^{1-\epsilon}] \leq O(1/n^{n^{1-\epsilon}})$——即空间以双指数级高概率保持线性。

**近乎最优性**：[引理 3](引理3的证明.md) 证明，若失败概率达到 $1/n^{n^\epsilon}$，则存在确定性常数时间字典（一个著名的开放问题）。
